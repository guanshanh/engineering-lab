# Redis 简介

Redis（Remote Dictionary Server）是一个开源的内存数据结构存储系统，由 Salvatore Sanfilippo 在 2009 年创建。

## 核心特性

Redis 支持多种数据结构：

- **字符串（String）**：最基本的数据类型，可以存储文本或二进制数据，最大 512MB。
- **哈希（Hash）**：键值对集合，适合存储对象。
- **列表（List）**：有序的字符串列表，支持从两端插入和弹出。
- **集合（Set）**：无序的唯一字符串集合，支持交集、并集、差集运算。
- **有序集合（Sorted Set）**：每个成员关联一个分数，按分数排序。

## 持久化

Redis 提供两种持久化方式：

### RDB（Redis Database）

RDB 在指定时间间隔对数据进行快照存储。优点是文件紧凑，恢复速度快；缺点是可能丢失最后一次快照后的数据。

### AOF（Append Only File）

AOF 将每个写操作追加到日志文件末尾。优点是数据安全性更高；缺点是文件体积大，恢复速度慢。

可以同时启用 RDB 和 AOF，Redis 重启时优先使用 AOF 恢复数据。

## 高可用

### 主从复制

Redis 支持主从复制（Replication）。主节点将数据同步到从节点，从节点可以处理读请求，分担主节点压力。

### Redis Sentinel

Sentinel 提供高可用性解决方案：
- 监控：检查主从节点是否正常运行
- 通知：当节点故障时通过 API 通知系统管理员
- 自动故障转移：主节点故障时自动将从节点提升为主节点

### Redis Cluster

Redis Cluster 是官方的分布式解决方案：
- 数据自动分片到多个节点
- 部分节点故障时集群仍可用
- 支持在线扩容和缩容

## 常见使用场景

1. **缓存**：最常见的用途，利用内存高速读写降低数据库压力
2. **会话存储**：存储用户登录 session
3. **排行榜**：利用有序集合实现实时排行榜
4. **消息队列**：利用 List 或 Stream 实现简单的消息队列
5. **分布式锁**：利用 SETNX 实现分布式锁
6. **计数器**：利用 INCR 原子操作实现高并发计数
